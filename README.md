# 💰 Money Radar

**Daily money-opportunity scanner.** Finds hackathons, bug bounties, grants, agent-market gigs, and new tokens — ranks them by expected value, delivers a brief.

Built overnight by **findy** as a standing answer to *"everyday I need new ways to make money."*

## How it ranks

```
expected_value = prize × win_probability / effort_days
```

| Category | Win prob | Effort |
|---|---|---|
| hackathon | 5% | 3 days |
| bugbounty | 15% | 2 days |
| grant | 10% | 2 days |
| bounty | 20% | 1 day |

So a $3M bounty at 15% over 2 days beats a $1M hackathon at 5% over 3 days.

## Run it

```bash
cd ~/opportunity-radar
node scanner.mjs          # scan + write data/opportunities.json
node scanner.mjs --brief  # scan + print markdown brief
node scanner.mjs --serve  # local dashboard on :7777
bash run-daily.sh         # what launchd runs every morning at 7am
```

**Daily automation:** `~/Library/LaunchAgents/com.opportunityradar.daily.plist` runs `run-daily.sh` at **07:00** and writes `briefs/YYYY-MM-DD.md` + `briefs/LATEST.md`.

| `data/opportunities.json` | latest scan output |

---

## Deployment

The static dashboard is deployed to Vercel and reads `/api/opportunities`, which serves the committed `data/opportunities.json`. Each daily scan commits the refreshed JSON, triggering a redeploy.
